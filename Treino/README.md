# Guia rápido de HTML e CSS — prova

Este repositório é um material de consulta com exemplos pequenos e comentados.
Abra os arquivos HTML no navegador ou use Live Server no VS Code.

## Por onde começar
1. `01-grid/grid.html`: três colunas e duas linhas.
2. `02-flexbox/flex.html`: logo e menu na mesma linha.
3. `03-pagina-exemplo/index.html`: exemplo de página completa.
4. Leia `resumo-prova.md` para consultar as propriedades rapidamente.

## Regra importante
- **Grid**: quando você organiza itens em linhas e colunas.
- **Flexbox**: quando você organiza itens principalmente em uma direção (linha ou coluna).
- `gap`: espaço entre os itens.
- `padding`: espaço dentro de um elemento, entre a borda e o conteúdo.
- `margin`: espaço fora do elemento.
